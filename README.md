# Sala de Tela

Aplicativo Windows para compartilhar tela e áudio em salas.

[Baixar instalador automático](https://github.com/xDreezyn/SalaDeTela-updates/releases/latest/download/SalaDeTela-1.4.1-Setup.exe) · [Passo a passo](https://github.com/xDreezyn/SalaDeTela-updates/releases/latest/download/LEIA-ME.md)

Windows 10 build 19041 ou superior, 64 bits. A primeira instalação baixa cerca de 161 MB da distribuição oficial FFmpeg e verifica a integridade. Playit é opcional; também há rede local e integração opcional Tailscale. Leia o passo a passo antes de convidar amigos.

Este repositório publica apenas instaladores, pacotes e catálogos assinados. Código e versão Dev são privados. Testes locais passaram; validação entre redes externas e em outros PCs continua necessária. Veja as limitações nas notas do release e no guia.
